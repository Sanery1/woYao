# 贯穿例子

售后知识库查询“手机维修”，沿用四篇长度50/150/300/100、维修次数1/3/3/0的教学文档。把“退货/退款”作为同一知识库的词汇不一致变式。

# 大纲

1. 先找进候选，再排先后（G1）
2. 三种证据共同决定贡献（G2）
3. 沿四篇文档比较，观察联动变化（G3）
4. 把投诉变成可验证的任务（G4）
5. 标题与正文分别提供什么证据（G5）
6. 回到开头

# 学习目标题

### G1〔过程〕从输入“手机维修”到显示结果，候选与排序分别做什么？
- 负责节：§1
- 答案要点：
  - 分析程序先得到词项，查询与文档用兼容规则。
  - 索引定位候选，BM25给候选计算词项贡献并排序。
  - 查询约束能改变候选，不能把一切归因于BM25。

### G2〔为什么〕为什么某篇文章多写十次“维修”，不保证分数或用户价值增加十倍？
- 负责节：§2
- 答案要点：
  - 重复词频的额外收益递减，k1控制饱和。
  - 相对平均长度也参与调整，b控制力度。
  - 词项匹配强度不是用户价值或相关概率。

### G3〔为什么〕长汇总与普通指南都出现3次“维修”，为什么前者这个词的贡献更低？追加词后又该检查哪些量？
- 负责节：§3
- 答案要点：
  - 长汇总相对平均长度更大，同次数经长度调整后证据更弱。
  - 真追加词同时改变词频和文档长度，也可能改变平均长度。
  - 新贡献需要重新比较，不能只看次数；也不能保证超过其他文档。

### G4〔迁移/判断〕搜“退货”而相关文档只写“退款”，工程师建议先调b，你会先确认什么？
- 负责节：§4
- 答案要点：
  - 先检查相关文档是否进入候选及实际词项、同义词等机制。
  - 排序参数不能建立不存在的词汇联系。
  - 用固定查询和相关性标注验证，分别看候选覆盖和前排效果。

### G5〔判断〕产品希望标题命中更重要，字段权重与长度调整分别解决什么，怎样判断修改有效？
- 负责节：§5
- 答案要点：
  - 权重表达字段证据相对重要性，字段长度调整补偿该字段长短差异。
  - BM25F先合并经过调整与加权的字段词频再统一饱和，不等于各字段分数简单相加。
  - 业务假设须用固定任务与标注验证，分数升高不证明用户收益。
