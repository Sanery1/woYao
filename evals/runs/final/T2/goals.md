# T2 写作前固定目标

固定时间：2026-11-25；woYao 0.19.0-preview.5。读者会 Python，第一次写 Agent；用途为动手实现，标准篇幅，只要 Markdown。

1. 用一个计算报价的案例解释模型请求工具、宿主执行、结果回传、模型最终回答的完整控制流。
2. 能独立配置 Python 标准库实现的 OpenAI Chat Completions 兼容客户端，并理解端点、模型、密钥与兼容边界。
3. 能逐步构建工具 schema、白名单分发、参数验证、消息关联和有终止上限的循环。
4. 能区分工具错误、协议错误、HTTP 错误与预算耗尽，按可观察结果定位问题。
5. 用本地 mock 实测正常、多个工具、工具失败与上限分支；理解其不能证明真实模型兼容或任务正确。

## 研究问题地图

核心：tool_calls 的消息形状与 tool_call_id、arguments 为 JSON 字符串、何时继续/结束、失败处理。
先修：HTTP POST 与 JSON 序列化；Python 列表作为对话状态；函数映射而非任意执行。
深入：控制权与能力边界、单轮多调用、工具结果只为数据、预算与兼容方言。
延伸不做：框架、向量库、生产部署、持久化、多 Agent、付费调用。
