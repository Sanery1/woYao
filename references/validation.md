# 验证边界

## 内容

- 术语消歧、版本明确，机制/比较/数字有可定位证据；声明、观测、假设和例子分层。
- 问题地图随主题变化，补过关键隐含缺口；模式服务相应读者任务。
- 案例贯穿过程，图/正文一致，算例正确；比较说明任务、版本、指标与代价。
- 文末题是宏观认识，正文逐题有答案；`oOO!` 简短精准，不引新断言。

严重事实错误、伪造引用/结果/许可、泄露资料或错误覆盖直接判失败，分数不能掩盖。

## 自动检查

`check_document.py` 检查 Skill 发布版本、元信息、标题/围栏、默认尾部、题数提示、相对图片与哈希，提供 PDF 时检查首页 Skill 版本、标题和章节文字顺序。渲染器实际解析图和数学、阻断联网并检查横向溢出。发布器只接受与构建一致的候选。自动检查不判断来源支持、题目宏观性或读者理解。

实际看 PDF 每页，修复发现的问题并重建，不手改 PDF。只报告真实命令与结果；未检查项目明示。

## 回归与评测

`python -X utf8 tests/test_pipeline.py -v` 验证发布不变量：失败保留旧文件、哈希变化拒绝、图片路径边界、部分发布失败回滚。`python -X utf8 tests/test_renderer.py -v` 运行真实浏览器，覆盖中文、三类 Mermaid、行内/独立公式、代码美元、HTML 指令作为文本、错误语法/缺图/远程图失败与旧构建保留。长文、本地图、表与链接还需文档级样本回归。

研究质量需另跑真实任务：JEV 消歧/未知/可比路线；BM25 公式/算例/分词/比较；LangGraph State/调度/持久化/副作用；五模式区别；材料与源码冲突；无网络/PDF 工具降级；同主题授权更新。

旧样稿重渲染只证明兼容，短文不证明深度，Windows 成功不证明多宿主可用。跨平台确认须记录宿主版本、调用、依赖和实际双产物。未做的研究评测、读者复述及平台运行一律标未测试。


## 发布前的行为评测

记录用户请求、模式/范围选择、主要产物、实际执行和未验证项。用同一主题分别请求系统学习、快速、tutorial 和 reference，按 writing-modes.md 的完成条件评审；不以字数作为通过条件。快速应减少旁支覆盖，仍核验核心事实；只要 Markdown 时不启动 PDF 流程。此类评测需要真实 Agent 任务，脚本文本匹配不能替代。

当前工程回归额外覆盖伸缩括号/嵌套分式 SVG 完整性、公式末尾符号、缺失/错误版本和历史清单校验。测试通过不代表五种模式已完成独立行为评测。
