# 图

一图一问。图上方写“这张图回答：……”，下方解释状态变化/箭头/读图结论。图文中的证据与数字遵循 [evidence](evidence.md)。

| 内容 | 表达 |
| --- | --- |
| 步骤、分支、数据流 | Mermaid flowchart |
| 多方调用次序 | Mermaid sequenceDiagram |
| 状态转换 | Mermaid stateDiagram-v2 |
| 数值变化 | calc 生成 SVG；有 matplotlib 时复用，没有时表格 |
| 同一对象的多步状态比较 | 可手写 SVG，保留图源 |
| 方案对比 | 表格并解释选择 |

每个核心机制优先一张有信息增量的图；节点名尽量≤12字、节点≤12个，复杂图拆开。图数参考 planning，不为满足数量添加无用图。教学简化标〔示意〕，同一种颜色保持同一角色含义，并配文字或线型。

Mermaid 围栏直接写正文。支持 GitHub/编辑器预览；HTML 通过 scripts/html/export.cjs 内联 Mermaid，无图时不包含图形库。使用普通 Mermaid 语法，配置由导出器统一设定。禁用脚本时保留源码可读。

HTML 查看桌面与窄屏：图是否实际渲染、标签/连线是否裁切、页面是否横向溢出、离线是否请求外网。打印前等图渲染完，检查打印预览；不能仅凭文件生成就报告视觉通过。
