# 追问与修订

先定位现有 report 和对应 brief/map，保留原题、证据及运行记录。

## 某节没懂

能定位卡点时直接处理；无法判断时只问“卡在哪一句或哪一步？”。区分术语未解释（T2）、过程跳步（T4）、例子不具体（T3）及抽象缺对应（T5）。

改写前保存到 `_work/report.vN.md`，N 为尚未存在的递增号，拒绝覆盖快照。仅替换目标节，保留其他节原字节；若必须调整依赖节，先说明具体影响范围。追加 review 修订记录（日期、节、原因、改动），重新运行 check，只用原有目标题中该节负责的题重测，不能降低答案要求。

## 继续深入 X

原 G1–G5 不变；在 map 的 `# 扩展学习目标题` 下追加 G6 起的1–2题并标负责节/答案要点，先补证据。新节放 `## 回到开头` 之前；原预算不够时与用户确定改深度或单独生成扩展报告，不能静默突破上限。check 后只测新增题，按每题2分换算80%门槛，保留原五题分。

## 换读者/缩短

新建 `report.A.md` / `report.B.md` / `report.C.md`；短版 `report.brief.md` ≤1500字。对应新 brief/map 保存 `_work/variants/report.A/` 等目录，原 report 和原 brief/map 不动，证据/calc 可复用。新文件存在时选递增文件名。

用 `check.py <topic-dir> --report report.A.md` 校验对应版本；按新读者和深度重测，不能沿用旧分。缩短时每个核心问题一段，保留 `## 回到开头` 及文末辅助章节。
