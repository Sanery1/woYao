# HTML 与自适应论文风机制图（预览设置）

## 阅读与深度

默认是可连续阅读的技术文章：短导入后逐层进入机制、抽象、实现与取舍。保留必要公式、代码、来源和失效条件；通过组织顺序减少阅读负担。目录用于导航，关键解释默认展开。

按 [写作规则](writing-modes.md) 用算例、运行过程或论证等方式完成解释链，按主题选择合适图型。图和邻近文字共同完成推理：图显示对象或状态的变化，文字解释看哪里、为什么变化、得到什么结论。正式术语在需要时定义，避免用对象词典开场。

复杂过程可拆成连续画格，保持角色位置、颜色和消息身份一致。图数随问题决定；四幅故障恢复图是例子，不是所有报告的固定章法。压缩重复摘要，把重点放在新增认识上。

## 按内容自动选择图的样式

默认在以下三种方向中选择。A/B/C 是本 Skill 的风格简称，参考用户选定的 Paper Framework Figure Studio Pro 样图，不是第三方官方预设名。先确定要解释的问题、必要对象与关系，再选布局和外观；无需让用户逐图选菜单。

| 方向 | 适合的内容 | 默认表达 |
| --- | --- | --- |
| A：分步骤模块化论文图 | 多阶段方法、系统总览、模块内机制需要适量展开 | 阶段编号、浅色语义分组、清楚主路径；局部小图展示实际机制 |
| B：轻量线稿流程图 | 请求生命周期、调用顺序、反馈环路、故障与恢复过程 | 短标签、轻框线、准确箭头，突出先后与分支；必要时拆连续图 |
| C：正式论文线稿 | 高密度架构、双路径/双空间对照、公式与变量关系、严谨机制说明 | 对齐分区、细线、少量强调色，紧凑而可读，图例与符号统一 |

一份报告可包含多种图型，保持统一字体、颜色语义与线型规则。图型可结合：例如 A 呈现系统总览，B 解释其中一次调用，C 展开需要严谨对照的机制。内容适合简单时间轴或数据图时，使用相应图型并沿用这些视觉原则，不把所有内容强塞进模块框。用户指定风格优先。

图内文字默认使用清楚的正常无衬线字体，与正文协调；代码、变量与公式保持各自规范。此前的漫画图字和手绘边框不再默认使用；随包霞鹜漫黑及历史示例保留，用户明确要求漫画风时可复用。嵌入字体保留授权，核对真实标签的字形覆盖与加载；使用宿主现有字体/工具，避免为样式引入新的硬性环境前置条件。

## 共同构图与风格设置逻辑

先判断图是否能呈现文字难以直接表达的状态、顺序、数量或结构差异。仅把术语排列进框时，改用具体对象和状态，或保留为简短文字。例如脚本恢复图可分首次执行、崩溃、恢复三阶段，区分读取已存结果与真正访问外部服务；不要求所有主题套用此图型。

每幅重要图在内部简要确定：读者问题、必要节点与关系、阅读路径、信息密度、图文分工、箭头/线型语义、配色和字体。信息密度以在正文宽度下能读清为准；拆图优于缩小所有标签。

主机制最突出，背景与图例从属。局部面板展示新增机制，并用标注线关联主图；标注线与真正的数据/控制流箭头明确区分。指标、阈值、概率等适合放在边或端口上的信息，按其含义标注，不随意变成与处理模块并列的方框。每张图回答一个具体问题，图题交代教学简化与必要假设。

采用浅色背景、克制的主强调色与辅助色，同一颜色不混用不同角色，含义同时用标签、形状或线型区分。留白服务于分组、连线与可读性；重复对象用代表实例、分组或省略标记表达，比较所需的真实差异保留。时间刻度、数值位置与方向保持准确。框内可用小图解释机制，避免仅堆模块名称。

风格逻辑参考 [Paper Framework Figure Studio Pro](https://github.com/c-narcissus/paper-framework-figure-studio-pro) v3.2.15f 的风格组合、语义与视觉分离、密度和图文分工方法；适配为本报告流程，不引入其固定候选批次、论文专用面积比例或多阶段人工确认。图中事实与关系仍以本次研究证据为依据，样图只提供视觉参考。

关系用结构图，调用先后用时序图，状态变化用状态图，耗时比较用时间轴；手写 SVG 或已有 Mermaid 等能力均可，按问题选取。吸收画图 Skill 的布局与检查方法，无需整套安装。官方原图在许可合适、确实帮助解释时使用，保留来源并配文字。

默认静态 SVG，内嵌到 HTML，保留可编辑图源。需要精确工程图时以准确表达优先。只有改变输入确实帮助推理时添加小范围交互；默认状态和禁用脚本时仍保留完整主结论。

## HTML 交付

浅色、克制、单栏正文配轻量目录；正文以正常中文黑体约 16–18 px 作为起点，按实际显示调整。图、表和公式就近嵌在解释段落中。窄屏目录可收起，宽图可局部滚动并放大，不能让全页横向溢出。

交付独立 HTML：图形、样式在文件内，字体默认使用系统中文字体；需要指定图字字体时在 SVG 中嵌入获许可的字形。正文阅读不依赖 CDN、在线字体或脚本库下载。外部引用链接可联网回查。交互保持少量，如目录和图形放大；打印样式按需提供，未经实际检查不声称 PDF 可用。

默认导出：

```text
node <skill-dir>/scripts/export_html.cjs <report.md> [--output <新文件.html>]
```

入口复用 `assets/report-html.css` 与 `assets/report-html.js`，支持标题目录、表格局部滚动、图片放大和离线数学公式；不启动浏览器。默认在正文旁生成同名 HTML，已有文件拒绝覆盖。正文与图源留在原目录；自包含 HTML 可单独分享。普通 Markdown 无需品牌章节。

复用 `scripts` 中已有锁定依赖；缺少时运行 `npm ci --prefix <skill-dir>/scripts --ignore-scripts --no-audit --no-fund`，无需下载浏览器。图片须在正文目录内以相对路径引用；远程图先依法取得本地文件。HTML 图使用本地 SVG/PNG 等；Mermaid 围栏需先用可用工具转为 SVG，否则入口明确报错。公式使用 `$...$` 或独立 `$$...$$`，无效公式报错。原始 HTML 按文本显示。转换器不修改正文、不自动补 Skill 版本、不证明教学质量；无法完成时保留正文并说明原因。

## 复核与样例

实际查看桌面与窄屏效果及每幅图；检查字体、缺字、标签和箭头裁切、局部滚动、放大、来源锚点，以及离线和禁用脚本阅读。确认 Markdown 与 HTML 内容一致。格式检查不能证明读者理解；通过试读定位卡点，继续修订。

包内历史漫画风 [故障恢复试读](../examples/recovery-html-v2/故障恢复-漫画图解.html) 展示正常发送、崩溃、重复与身份核验；对应 Markdown 和 SVG 同目录。该例显示生成时基线 v0.18.1，保留历史标记，不据此推断原型 API 或固定所有报告章节。用户已反馈其逐步解释比前版好读；该例保留原样，不代表本版 A/B/C 默认外观。Pi Durable 已试用 A/B/C 自动选型；后续以完整案例闭环与图的信息增量复核，跨主题及跨宿主效果仍需验证。
